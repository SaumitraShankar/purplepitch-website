# Purple Pitch website

Static single-page site for Purple Pitch (Kahaniyon ka Prime Time), served by GitHub Pages.

- index.html: the site
- og-image.jpg: WhatsApp / LinkedIn share preview
- favicon.svg, favicon-32.png, apple-touch-icon.png: browser and phone icons

To edit, change index.html and commit. Changes go live in about a minute.
